# Racha Contas

App simples para acompanhar contas que você paga e divide com outras pessoas.
Mostra a parte de cada pessoa, permite confirmar o recebimento mês a mês e avisa sobre cotas atrasadas ou perto de vencer.

- Funciona offline (PWA): instale pelo navegador do celular em "Adicionar à tela inicial".
- Os dados ficam salvos só no aparelho (localStorage). Use **Exportar backup** de vez em quando.

## Publicar no GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → Branch `main` / pasta `/ (root)`.
